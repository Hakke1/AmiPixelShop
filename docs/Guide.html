1. About

AmiPixelShop is a modern, layer-based image editor written natively for the Amiga. It is not a port and nothing was reverse-engineered: every function was rebuilt from scratch in C and 68k assembler, modelled on the workflow of today's professional image editors.

This is an early beta. Expect bugs - and please report them (see Reporting bugs).

2. Requirements

CPUPiStorm (Emu68, JIT-emulated 68040 with FPU) - recommended and tested.
A real 68060 with FPU might work, but will be slow at high resolutions (untested).
GraphicsRTG (Picasso96 / P96) with a 24 or 32 bit screen mode.
Supported resolutions: 1024×600 up to 1920×1080.
OSAmigaOS 3.2 (tested with 3.2.3).
MemoryAt least 128 MB Fast RAM, more for large images. A layer of 1920×1080 needs about 8 MB.
Tested onAmiga 500 + PiStorm (Raspberry Pi 3A+, Emu68), AmigaOS 3.2.3, P96.

3. Installation

  1. Unpack the archive anywhere, e.g. Work:. You get a drawer AmiPixelShop.
  2. Start AmiPixelShop from Workbench or from the Shell.
    From the Shell you can pass an image: AmiPixelShop Work:Pictures/photo.jpg
  3. For the Type tool you need TrueType fonts (.ttf / .otf) in FONTS:truetype/, FONTS:_ttf/ or in a Fonts drawer next to the program.

Preferences are stored in ENV:AmiPixelShop.prefs and ENVARC:AmiPixelShop.prefs. Delete these files to reset all settings.

4. First start and screen mode

On the first start a screen mode requester appears. Choose an RTG mode with 24 or 32 bit (only suitable modes from 1024×600 to 1920×1080 are listed). AmiPixelShop opens its own screen for maximum speed. The choice is saved; change it later with Edit > Screen Mode... (takes effect on the next start).

5. The workspace

Menu bar (top) - all commands. Entries that cannot be used right now are greyed out. Menus are opened with a click (not with the right mouse button).

Options bar (below the menu) - settings of the current tool:

Toolbar (left) - all tools. A small triangle means there are more tools in the same slot: hold the mouse button or click with the right button to choose. Hover over a tool to see a short tooltip. With Edit > Toolbar... you choose which tools are shown.

Below the tools: foreground and background color. Click to open the Color Picker, X swaps them, D resets to black/white.

Document tabs - several images can be open at once. Ctrl+Tab switches.

Panels (right) - Color/Swatches, Properties and Layers/History.

Status bar (bottom) - zoom, document size, redraw time and messages.

Navigation: hold Space and drag to scroll, mouse wheel or Ctrl++ / Ctrl+- to zoom, Ctrl+0 fits the image, Ctrl+1 shows 100%.

7. Layers, groups and masks

Layers panel: click the eye to show/hide a layer, click a row to make it active, drag rows to change the order or to drop a layer into a group. Double-click the name to rename.

Each layer has a blend mode (Normal, Multiply, Screen, Overlay, Soft Light, Color, ... 25 modes), Opacity and Fill. Lock: transparency, pixels, position or all.

Several layers: Ctrl+click adds a layer to the selection, Shift+click selects a range, Select > All Layers (Alt+Ctrl+A) selects all. Selected layers can be moved, grouped (Ctrl+G), merged (Ctrl+E) or deleted together.

Groups (Ctrl+G): fold open/closed with the triangle, blend mode Pass Through or isolated, with opacity and mask.

Layer masks: button at the bottom of the panel or Layer > Layer Mask. Click the mask thumbnail to paint into the mask (black hides, white shows), Shift+click disables it. The small chain between the thumbnails links layer and mask - they move together. Click the chain to unlink them.

Clipping masks (Alt+Ctrl+G): a layer is only visible where the layer below has pixels.

Adjustment layers (round button at the bottom, or Layer > New Adjustment Layer): non-destructive Brightness/Contrast, Levels, Curves, Hue/Saturation, Desaturate, Invert, Threshold, Posterize.

Layer styles (fx button): Drop Shadow, Outer Glow, Stroke.

8. Properties panel

Shows the settings of the active layer - click its header to fold it away:

  • Adjustment layer: its sliders, live. Curves: button Edit Curves...
  • Type layer: size, tracking, leading and alignment
  • Pixel layer: position and size, Free Transform, Flip
  • Group: number of layers, Ungroup, Merge Group
  • Layer mask: Invert, Apply, Disable/Enable, Delete

9. Selections

  • Marquee, Lasso, Quick Selection and Magic Wand tools (see Tools).
  • Select > Color Range... - selects by color with fuzziness, with live preview.
  • Select > Grow / Similar - extends the selection to similar colors (uses the Magic Wand tolerance).
  • Select > Modify - Feather, Expand, Contract.
  • Select > Inverse (Shift+Ctrl+I), Reselect (Shift+Ctrl+D).
  • Edit > Fill... and Edit > Stroke... (inside, center or outside).
  • Ctrl+J copies the selection to a new layer, Shift+Ctrl+J cuts it.

10. Type

Choose the Type tool, click into the image and type. Return starts a new line, Ctrl+Return or the Commit button finishes, Esc cancels. Click an existing text with the Type tool to edit it again.

Options bar and Type menu: font, size, alignment (left / center / right), anti-aliasing (Smooth, Sharp, None), Character... (tracking and leading), Paste Lorem Ipsum. Layer > Rasterize Type turns text into pixels.

11. Pen tool and paths

  • Click sets a corner point, drag sets a curve point with handles.
  • Click the first point to close the path. Return ends an open path, Backspace removes the last point.
  • Drag points or handles to edit the path.
  • Options bar: Make Selection (also Ctrl+Return), Fill Path (foreground color), Stroke Path (with the current brush), Delete Path.

12. Adjustments and filters

Image > Adjustments: Brightness/Contrast, Levels (Ctrl+L), Curves (Ctrl+M), Hue/Saturation (Ctrl+U), Desaturate, Invert (Ctrl+I), Threshold, Posterize - all with live preview.

Filter: Box Blur, Gaussian Blur, Motion Blur, Add Noise, Median, Mosaic, Sharpen, Sharpen More, Unsharp Mask, Emboss, Find Edges, High Pass. Ctrl+F repeats the last filter. With a selection, filters only work inside it. With a mask active, they work on the mask.

Image: Image Size, Canvas Size, Image Rotation (180°, 90°, arbitrary, flip canvas), Crop, Trim, Reveal All, Duplicate.

Edit > Transform / Free Transform (Ctrl+T): scale, rotate, flip - Return applies, Esc cancels.

Pixels moved outside the canvas are kept and come back with Image > Reveal All or when moved back.

13. File formats

FormatOpenSaveNotes
.apsyesyesNative format: keeps layers, groups, masks, styles, adjustment layers and editable text.
.psdyes-Layered files (RGB or grayscale, 8 bit): layers, groups, masks, clipping masks, blend modes, opacity. Text and smart objects come in as pixels, layer effects are not imported. Files too large for the memory open flattened.
.pngyesyesWith transparency.
.jpgyesyesFlattened, quality 90.
otheryes-IFF ILBM, GIF, BMP and more via installed datatypes.

Copy and paste work with the Amiga clipboard (Ctrl+C / Ctrl+V), also File > New from Clipboard.

15. Known limitations (early beta)

  • 8 bit per channel RGB only; no CMYK, no 16 bit.
  • Up to 64 layers per document.
  • Paths are not part of Undo and are not saved yet.
  • PSD files can be opened but not saved.
  • Very large images need a lot of memory (each layer is stored as full 32 bit tiles).
  • No graphics tablet support.
